# Бинго «Что? Где? Когда?»

Unity 6.3 (6000.3.9f1). Откройте **Assets/_Content/Scenes/BingoApp.unity** и нажмите Play. Эта сцена уже выбрана в Build Settings. Старые сцены оставлены в проекте для справки.

## Игра

- Обычная игра и финал серии: 3×3. Финал года: 5×5.
- Нажатие на клетку ставит или снимает отметку. Полностью отмеченные строки, столбцы и обе диагонали считаются автоматически. Центральная клетка содержит заданное событие; она не отмечается бесплатно.
- Каждый режим хранит собственную незавершённую партию. Возврат в меню и повторное открытие восстанавливают фразы, порядок, номер партии и отметки. Сохранение происходит при каждом изменении через PlayerPrefs.Save().
- «Завершить партию» после подтверждения удаляет сохранение только выбранного режима. Следующая игра получает новую карточку и следующий номер.
- «Сохранить в PNG» создаёт карточку 1080×1536 с заголовком, статистикой и отметками. Кнопки интерфейса в изображение не попадают. В браузере файл скачивается через JavaScript-плагин; в редакторе открывается диалог сохранения; в настольной сборке файл сохраняется в Application.persistentDataPath.
- Escape закрывает диалог или возвращает из игры в меню.

Сохранения локальны для браузера, устройства и адреса сайта. Очистка данных сайта удаляет их; перенос между хостингами не переносит партии. Старые версии приложения не хранили партии, поэтому мигрировать из них нечего.

## Оформление и данные

Интерфейс создаётся из UGUI и TextMesh Pro при запуске; вертикальное и горизонтальное расположения выбираются по размеру окна. Палитра и элементы оформления находятся в `BingoStyle.cs`, векторные значки — в `BingoIcon.cs`, экран игры — в `BingoView.cs`, меню — в `MainMenuView.cs`.

Логотип совы в верхней балке загружается из `Assets/_Content/Sprites/Resources/icon_main_menu_logo.png` и сохраняет пропорции исходного изображения. Он используется в меню, на экране игры и в экспортируемой PNG-карточке. Чтобы обновить логотип, замените этот файл.

Фразы и ограничения категорий редактируются в существующих `Assets/_Content/Data/BingoPreset*.asset`. Категория Uncategorized может повторяться, остальные категории встречаются на карточке не больше одного раза. Центральная фраза задана отдельно в пресете. Генератор сообщает об ошибке, если после применения ограничений фраз недостаточно.

Шрифт PT Serif с кириллицей: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ptserif). Лицензия SIL OFL включена в `Assets/_Content/Fonts/OFL.txt`.

## Web-сборка

В Unity выберите Web в Build Profiles, включите сцену BingoApp и соберите проект. Для локальной проверки используйте HTTP-сервер вместо открытия index.html как файла. Пункт меню **Bingo → Build Web (local preview)** собирает в `Builds/WebGL`.

Для itch.io загрузите ZIP с index.html в корне и включите запуск HTML в браузере. Для GitHub Pages разместите содержимое Web-сборки в публикуемой папке. Если хостинг не настраивает заголовки сжатия, используйте Decompression Fallback либо отключите Compression Format в Web Player Settings. Размер iframe рекомендуется от 960×640; портретная ориентация также поддерживается.

Скачивание PNG реализовано в `Assets/Plugins/WebGL/BingoDownload.jslib` через Blob и ссылку download. Если игра размещена в собственном sandbox-iframe, ему требуется `allow-downloads`. Механизм JS-плагинов описан в [руководстве Unity](https://docs.unity3d.com/Manual/webgl-interactingwithbrowserscripting.html); локальное хранение PlayerPrefs в Web — в [справке Unity](https://docs.unity3d.com/ScriptReference/PlayerPrefs.html).

## Проверка

Пункт **Bingo → Verify logic and render previews** проверяет генерацию 300 карточек, ограничения категорий, центральные клетки, подсчёт линий, сохранение/восстановление, независимость режимов, завершение и повреждённые сохранения. Проверка использует отдельные ключи и не меняет игровые сохранения.

Результат и PNG-превью всех режимов в обеих ориентациях появляются в `Logs/BingoVerification`. Для пакетного запуска: Unity с `-batchmode -projectPath <project> -executeMethod BingoVerification.Verify -quit -logFile <log>`; проект не должен быть одновременно открыт другим процессом Unity.
